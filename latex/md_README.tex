{\bfseries{vhost-\/switch}} is a DPDK-\/based vhost-\/user backend that acts as a {\bfseries{high-\/performance network switch}} for VMs\+:


\begin{DoxyEnumerate}
\item {\bfseries{VM-\/to-\/\+VM communication}}\+: Forwards packets between VMs based on MAC addresses (software switching)
\item {\bfseries{VM-\/to-\/\+Physical NIC}}\+: Forwards packets from VMs to the physical network interface
\item {\bfseries{Physical NIC-\/to-\/\+VM}}\+: Receives packets from the physical NIC and delivers them to the appropriate VM
\item {\bfseries{MAC learning}}\+: Learns VM MAC addresses from the first packet and maintains a forwarding table
\item {\bfseries{High performance}}\+: Uses DPDK for zero-\/copy, low-\/latency packet processing
\end{DoxyEnumerate}

{\bfseries{Packet flow\+:}}
\begin{DoxyItemize}
\item {\bfseries{VM → VM}}\+: Packet from VM1\textquotesingle{}s virtio TX queue → vhost-\/switch → VM2\textquotesingle{}s virtio RX queue
\item {\bfseries{VM → Physical}}\+: Packet from VM\textquotesingle{}s virtio TX queue → vhost-\/switch → Physical NIC TX
\item {\bfseries{Physical → VM}}\+: Packet from Physical NIC RX → vhost-\/switch → VM\textquotesingle{}s virtio RX queue
\end{DoxyItemize}

The switch worker loop continuously\+:
\begin{DoxyItemize}
\item Drains packets from physical NIC RX queues and delivers to VMs
\item Drains packets from VM virtio TX queues and routes them (to other VMs or physical NIC)
